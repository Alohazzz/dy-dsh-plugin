# 研发工作台 v0.3.0

交付计划新增方案审核、过程文档归档和计划完成报告。合并请求详情支持直接批准、合并或关闭 Codeup 合并请求（MR）。

## 交付计划与议题档案

- 方案调研分别保存调研报告和执行方案。可按议题、模块或关键词查阅历史档案。送审、退回和批准均关联具体的方案版本，执行时核对当前获批版本。版本化文档模板随插件安装。（GitHub #26、#27、#29、#30，`4c9bfbd`）
- 计划记录初始范围和成员变动。执行小结确认后，可按议题关联实际 Git 提交。向云效发布测试评论时，档案保留最终确认正文和回执。远端已发布但本地保存失败时，重试会补存回执。（GitHub #28、#31、#32，`4c9bfbd`）
- 关联 MR 后可生成并审核计划完成报告。关闭计划时保存终稿和遗留事项去向。无需继续的交付计划可作废，历史记录可在「已作废」列表查看。计划详情增加议题阶段和回写状态徽标。（GitHub #33，`4c9bfbd`、`6162504`、`fb5d681`）
- 修复调研回复缺少草稿标识时的回收问题。插件根据 DSH 会话历史核对回复归属，旧执行请求仍可重试。（`49f0dbf`）

## 合并请求

- MR 详情可批准、合并或关闭 Codeup MR。提交前核对远端状态和补丁集，提交后回查结果并刷新关联计划。合并保留源分支，操作受仓库评审规则和分支保护约束。（GitHub #14，`144b85b`）
- 修复从交付计划发起 MR 时的审核人选择。（`4c9bfbd`）

## 安装与更新

适用的 DeepSeek Harness（DSH）版本范围为 `>=0.2.2-rc.3 <0.3.0`。已有交付稿与回执可按原格式读取。新归档写入计划所绑定工作区的 `docs/workbench/`。可在 DSH 插件页检查更新，或下载预构建安装包。[DSH 插件索引](https://alohazzz.github.io/dy-dsh-plugin/index.json) · [GitHub Releases](https://github.com/Alohazzz/dy-dsh-plugin/releases)
