## 影响范围与测试

测试范围为工作台的云效测试回写、旧交付稿读取和发布后回查。本正文为模拟示例。

| 用例 | 前置条件与步骤 | 预期及验证结果 |
| --- | --- | --- |
| T1 新稿回写 | 新稿只有测试段。打开回写预览，编辑测试正文并确认。 | 只新增一条测试评论，正文与确认版本一致。模拟通过。 |
| T2 旧稿与回执 | 分别打开旧双段稿、有方法回执的旧记录和已有测试回执的旧记录。 | 能预览测试正文，历史回执可查。已有测试回执时评论数不增加。模拟通过。 |
| T3 发布后重启 | 云效模拟客户端已接收评论，宿主未收到响应。重启并重试。 | 恢复原评论 ID，评论数保持为 1。首轮模拟回查未找到原评论，复测恢复成功。 |

### 待验证

T4 在隔离 Desktop profile 安装候选包，使用有评论权限的云效测试议题。打开旧交付稿，编辑测试正文并发布，重启后复查。预期云效只出现一条对应测试评论，回写面板显示同一个评论 ID。
