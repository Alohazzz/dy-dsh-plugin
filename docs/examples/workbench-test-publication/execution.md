# 执行小结 · 云效新增发布只包含测试

## 执行依据

依据模拟获批的 [执行方案 v1](proposal.md)。以下实施和验证结果为示例输入。

## 实际修改

工作台预览、编辑及确认入口改为按测试项发布。双段旧稿可以读取测试，旧发布记录按原位置映射，只读展示已发历史及已有回执。新版记录保留用户确认的测试正文。远端结果不明时按原回写标记回查并补存回执。

## 与定稿的偏差

无。模拟实施记录覆盖方案的四个步骤。桌面安装验证留在发布前验收。

## 验收结果

以下均为模拟记录。

| 用例 | 结果 | 证据 |
| --- | --- | --- |
| T1 新稿独立发布 | 通过 | 模拟请求只提交一条测试评论，正文与确认稿一致。 |
| T2 旧稿与回执 | 通过 | 两种测试标题均可读。重开已有测试回执的记录时，模拟写入计数为 0。 |
| T3 远端成功后响应丢失 | 首轮失败，复测通过 | 首轮重启时用重新生成的正文回查，标记不匹配。修复后使用原确认正文回查，恢复原评论 ID，模拟写入计数为 1。 |

## 待验证项

T4 需候选安装包和有评论权限的云效测试议题。在隔离 Desktop profile 安装后，打开旧交付稿，编辑测试正文并确认发布，再重启回查。预期云效只有一条对应测试评论，回写面板显示一致的评论 ID。由发布验收负责人在发版前完成。
