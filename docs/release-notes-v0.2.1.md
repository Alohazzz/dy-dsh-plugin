# 研发工作台 v0.2.1

修复 DSH Desktop 热更新插件后，研发工作台只显示标题和导航、内容区空白的问题。插件重新挂载时会重新加载样式，避免旧样式把内容挤出可视区域。（`ce8aa16`）

## 安装与更新

适用的 DeepSeek Harness（DSH）版本范围为 `>=0.2.2-rc.3 <0.3.0`。在 DSH 的插件详情页检查更新，或下载预构建安装包。[DSH 插件索引](https://alohazzz.github.io/dy-dsh-plugin/index.json) · [GitHub Release](https://github.com/Alohazzz/dy-dsh-plugin/releases/tag/v0.2.1)
