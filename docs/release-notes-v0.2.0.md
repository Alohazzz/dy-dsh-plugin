# 研发工作台 v0.2.0

从 v0.1.6 升级后，云效议题从交付计划统一调研、定稿和执行。研发工作台新增合并请求和技能管理入口。

## 升级须知

- 已移除 `/yunxiao start`、云效议题的直接开工入口和独立讨论入口。请先将议题加入交付计划，在「计划议题」中发起方案调研，确认最新方案后选择「标记定稿」，再选择「开始执行」。依赖旧命令的操作流程需要改用交付计划入口。（`b008eb3`）
- 执行前，在计划的主工作区或独立工作树中检出计划源分支，并在 DeepSeek Harness（DSH）中配置可用的模型提供方。（`d596041`、`b008eb3`）

## 交付计划与云效议题

- 创建计划时可生成或编辑源分支名，选择已有分支、创建新分支，或使用独立工作树。（`d596041`）
- 单条或多条议题可在计划中调研、批量答疑和修订方案。执行派发失败后可重试，并沿用原定稿、会话和首条消息。（`702b35a`、`b008eb3`）
- 加入计划时同步负责人、计划开始时间和「待开发」状态。移出计划时将云效状态回退到「已确认」并清空计划开始时间，保留负责人和计划完成时间。同时修复了加入计划时的状态流转问题。（#8，`efb5e1e`、`7d997c9`）

## 合并请求与技能管理

- 可按仓库查看 Codeup 合并请求，打开「待我审核」队列，或从交付计划关联和发起合并请求。（`f7cf3bb`、`d596041`）
- 可在后台拉取固定补丁集快照并取消进行中的拉取。拉取完成后可运行只读审查，并在核对报告后将报告回写为 Codeup 评论。（#12、#13，`722c3e7`、`7038336`、`d520c62`）
- 技能管理支持从公司 Git 仓库或本地目录查阅技能，并安装到项目、指定会话的 Agent 或 DSH 实例。插件内置中文技术写作规则，用于议题方案、交付稿和合并请求审查报告。（#18，`f7cf3bb`、`f071459`、`b008eb3`）
